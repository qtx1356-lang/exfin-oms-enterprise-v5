# Office Management System — Codester Media & Image Asset Requirements

This document provides exact Specifications for Codester marketplace preview media and icons.

## 1. Marketplace Preview Media Specifications

### Main Marketplace Preview Banner
- **Dimensions:** 800 × 400 pixels minimum (1200 × 630 or 16:9 ratio recommended).
- **Format:** JPG or PNG (high quality, non-interlaced, < 2MB).
- **Bundled Generated Asset:**
  `/src/assets/images/codester_preview_banner_1787452938050.jpg`
- **Design Elements:** Shows modern dashboard UI on desktop and mobile mockups with clean purple/violet typography ("Office Management System"), highlighting GPS attendance, AI receipt OCR, and real-time analytics.

## 2. Marketplace App Icon Specifications
