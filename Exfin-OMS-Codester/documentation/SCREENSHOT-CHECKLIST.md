# Exfin OMS — Codester Screenshot Checklist

To create an appealing Codester marketplace submission, capture high-resolution screenshots (1920x1080 for web, 1080x2340 for mobile) for each key feature below:

---

## Required Marketplace Screenshots

### Administrator Panel (Web / Desktop)
1. **Admin Login Screen**: `/admin/login` showing clean authentication interface.
2. **Admin Dashboard Overview**: Live attendance status, statistics cards, and activity feed.
3. **Pending Device Approvals**: Device approval queue displaying selfie image and hardware Device ID.
4. **User Management & RBAC**: Employee table, role editor dropdown (`SUPER_ADMIN`, `ADMIN`, `HR`, `TEAM_LEADER`).
5. **Real-Time Attendance Board**: Detailed view of checked-in staff, precise GPS addresses, and distance from office.
6. **Attendance Correction Modal**: Interactive correction window displaying time adjustment fields and history.
7. **Expense Claims**: Expense grid with category filters and uploaded receipt viewer.
8. **Leave Management**: Leave approval table with balance badges and status indicators.
9. **Work Planner**: Task board displaying reassigned tasks, priority badges (`URGENT`, `HIGH`), and progress status.
10. **Employee Efficiency**: Performance metrics chart and daily efficiency score cards.
11. **Reports & Exports**: Attendance, salary, and leave export tools.
12. **Audit Logs**: Immutable audit table displaying action categories, actor names, and timestamps.

### Employee Application (Web / Mobile)
13. **Employee Mobile Home**: Clean dashboard showing check-in card, today's shift status, and quick actions.
14. **GPS Check-In Screen**: 25m geofence indicator, mode selection (Office, WFH, Client Visit, Outdoor Work), and map/address view.
15. **Office Exit Checkout Confirmation**: Interactive modal asking exiting employee to confirm checkout outside 25m boundary.
16. **My Expenses**: Employee expense claim submission form with receipt attachment button.
17. **My Leaves**: Employee leave application form and leave balance history cards.
18. **My Tasks & Work Planner**: Task list showing assigned duties, due dates, and proof upload buttons.
19. **Employee Profile**: Personal details, assigned office, designation, and bound device status.

## Mandatory Sanitization Rules for Screenshots

When capturing screenshots for Codester listing:
- **NO Real Names**: Use fictional names (`Alex Taylor`, `Jordan Lee`, `Morgan Reed`).
- **NO Real Phone Numbers**: Use dummy numbers (`+1 555-0199`, `+91 9876543210`).
- **NO Real Email Addresses**: Use dummy emails (`alex@example.com`).
- **NO Real Firebase Credentials**: Ensure API keys or Firebase project IDs are blurred or hidden in screenshot code windows.
- **NO Real Employee Photographs**: Use fictional avatars or sample stock portraits.
