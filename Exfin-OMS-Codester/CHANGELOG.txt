Exfin OMS — Version History & Changelog
===========================================

Version 1.0.0 (Initial Commercial Release)
-------------------------------------------
- Complete Office Management System (OMS) package for Codester marketplace.
- Core Attendance Engine:
  * 25-meter radius office geofence verification.
  * Real-time GPS location acquisition with Haversine distance calculations.
  * Support for Office, Work From Home (WFH), Client Visit, and Outdoor Field Work modes.
  * Office Exit Detection workflow (`PENDING_FINAL_EXIT` & `FINALIZED_CHECKOUT`).
  * Manual checkout prompt for exiting employees while outside geofence boundary.
- Precise GPS Address Engine:
  * Standardized coordinate-keyed reverse geocoding.
  * Race condition protection for fast movement / asynchronous updates.
  * Memory and persistent address caching.
- Admin Attendance Correction:
  * Comprehensive administrator attendance correction flow.
  * Auto-resolution of previous status and state history.
  * Recursive Firestore payload sanitization preventing `undefined` field errors.
- Role-Based Access Control (RBAC):
  * Super Admin, Admin, HR, Team Leader, and Employee roles.
  * Device registration, approval workflows, and hardware binding.
- Full Suite Modules:
  * Expense Management with receipts and multi-tier approval.
  * Leave Management with allowance rules and balances.
  * Work Planner & Task assignment with revision requests.
  * Employee Efficiency tracking and daily performance snapshots.
  * In-app team messaging, group announcements, and targeted notifications.
- Architecture & Cross-Platform:
  * React 19 + TypeScript + Vite 6 + Express Node server.
  * Capacitor 8 integration with native Android Kotlin plugins for geofencing and boot listeners.
  * Offline-first architecture with queued synchronization engine.
